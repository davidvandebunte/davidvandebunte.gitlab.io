# Review

+++

We'll use "VGT" as an acronym for Visual Group Theory. See the [VGT Website](http://web.bentley.edu/empl/c/ncarter/vgt/) for a quick summary of the book, and in particular notice  the [VGT Errata](http://web.bentley.edu/empl/c/ncarter/vgt/errata.html). The website went down at one point; if this happens again see [Wayback Machine: VGT](https://web.archive.org/web/20230501000000*/http://web.bentley.edu/empl/c/ncarter/vgt/errata.html) to get to the errata (it seems to have been up for 14+ years, otherwise). The author points to [Group Explorer](https://nathancarter.github.io/group-explorer/index.html) several times in the text. It's functioning as of 2024-May and the questions based on it are helpful.

This review will rely on Inkscape heavily to construct answers; it's not clear what tool the author used for his drawings but it would work as well.
