### Exercise 7.77²

+++

![x](raster/2023-10-25T19-49-19.png)

+++

How can we say that [0,2] is an open set in ℝ ⊆ 𝕀ℝ (the subspace topology) if the subspace topology includes only points? All A ⊆ ℝ will only be points, so that even if we could find a B ⊆ 𝕀ℝ that would cover [0,2] via A ⊆ B ∩ ℝ, we could still only get points out of the definition.
